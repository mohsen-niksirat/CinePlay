## ✨ امکانات

### 🎯 پخش
- پخش آنلاین از **لینک مستقیم** (MP4 / WebM / MKV / M3U8 / M3U)
- پشتیبانی **HLS** با hls.js — کیفیت چندگانه + تعویض کیفیت بدون توقف
- **ادامه تماشا** — ذخیره خودکار موقعیت و ادامه از همان‌جا
- مدیریت خطا: retry خودکار، پیام‌های فارسی، تشخیص لینک مرده

### 🎛️ کنترل‌ها
- دهم ثانیه عقب/جلو + **دوبل‌تپ** چپ/راست (موبایل)
- سرعت پخش ۰٫۲۵× تا ۴×
- صدا و روشنایی با **سوایپ** (موبایل) — راست: صدا، چپ: روشنایی
- تمام‌صفحه، **PiP** (تصویر در تصویر)
- شورتکات کامل کیبورد (Space، جهت‌ها، F، M، S، …)

### 💬 زیرنویس
- **SRT / VTT / ASS(متن)** — پارسر داخلی، بدون سرور
- افزودن با انتخاب فایل 📁 یا لینک URL
- چند زیرنویس همزمان + سنکرون زودتر/دیرتر
- استایل کامل: اندازه، رنگ، سایه، موقعیت — فارسی RTL

### 🔊 نسخه‌ها (دوبله/زیرنویس‌دار)
- جابه‌جایی بین نسخه‌ها **بدون خروج از پلیر** با حفظ موقعیت

### 📺 حالت سریال
- پنل اپیزودها با گروه‌بندی فصل
- اپیزود بعدی/قبلی + پخش خودکار بعدی
- علامت دیده‌شده‌ها + درصد پیشرفت

### ✨ اضافه‌ها
- اسکرین‌شات از فریم (PNG)
- A-B تکرار، تایمر خواب، Skip Intro
- Zoom و نسبت تصویر
- آمار فنی: کدک، رزولوشن، بیت‌ریت، سلامت بافر
- دارک تم هماهنگ با سینما + PWA نصب‌شدنی

## 🚀 اجرا

```bash
# پوشه پروژه
python -m http.server 8000
# یا
npx serve .
# → http://localhost:8000
```

> **نکته:** برای اجرای محلی به سرور لازم است (file:// به‌خاطر Service Worker و CORS کار نمی‌کند).

## 🕹️ نحوه استفاده

1. صفحه اول → **لینک ویدیو** را بچسبانید (mp4/m3u8/…)
2. (اختیاری) عنوان، پوستر، زیرنویس، لیست اپیزودها را اضافه کنید
3. ▶ پخش!

### پارامترهای URL (برای اتصال برنامه‌های دیگر)

```
player.html?src=<لینک‌ویدیو>&title=<عنوان>&poster=<پوستر>&sub=<لینک‌زیرنویس>&imdb=<ID>&next=<لینک‌اپیزودبعدی>
```

| پارامتر | توضیح |
|---------|-------|
| `src` | لینک مستقیم ویدیو (encode شده) |
| `title` | عنوان نمایش‌داده‌شده |
| `poster` | پوستر (قبل از پخش) |
| `sub` | لینک زیرنویس (srt/vtt) |
| `imdb` | شناسه IMDb (برای ادامه تماشا) |
| `next` | لینک اپیزود بعدی |

همچنین با JSON در `hash`:
```
#j=<base64 از JSON>
```
